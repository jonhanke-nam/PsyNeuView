# Security

PsyNeuView runs Python model files: opening a model executes it. Treat model
files like any other code you run, and only open ones you trust.

## Reporting a vulnerability

Please **don't** open a public issue for a security problem. Use GitHub's
private vulnerability reporting instead: on this repository, go to
**Security → Report a vulnerability**. You'll get an acknowledgement, and we'll
keep you informed as the fix progresses.

Include what you can: the version (Settings → About), how to reproduce it, and
what an attacker could do with it.

## Supported versions

Fixes go into `devel` and ship in the next release. Older releases are not
patched separately.
