# PsyNeuView documentation

**PsyNeuView** is a GUI for building, running, and visualizing
[PsyNeuLink](https://princetonuniversity.github.io/PsyNeuLink/) models — load a
model, see its graph, run it, step through execution, and edit it live.

## Start here

- **Never used PsyNeuView?** Read [What PsyNeuView is](introduction.md) — a
  five-minute, no-setup overview of what the tool does and why. Then, in the
  app, take [PsyNeuView First Steps](psyneuview-first-steps.md): eight
  short walkthroughs of the window, your files, what it runs on, and running a
  model (Tutorials ▾ menu).
- **Ready to try it?** Begin with the [Tutorials](tutorials/README.md) —
  start with [Loading a model](tutorials/01-loading-a-model.md).
- **Building or running models?** The tutorials walk each workflow end-to-end;
  each one links the relevant PsyNeuLink concept at the bottom of its page.
- **Running it on your own machine?** [Getting Started](getting-started.md)
  is the local developer setup — clone, install, run on `devel`.
- **Already write PsyNeuLink models in an IDE?** [Two ways to
  work](workflow-modes.md) explains using PsyNeuView beside PyCharm — what each
  tool owns, and how edits flow between them.
- **Wondering why a file is read only, or where Save goes?** [What you can
  edit, and why](what-you-can-edit.md), and [Where PsyNeuView keeps
  things](where-things-live.md).
- **Advanced user or contributor?** See the **Developer** section
  (testing, conventions, internals).

!!! note "Looking for the modeling library?"
    PsyNeuView visualizes PsyNeuLink models. For the library itself — the
    concepts, classes, and full API — see the
    [PsyNeuLink documentation](https://princetonuniversity.github.io/PsyNeuLink/).
