## How to Test

### Web (Vite dev server)
```bash
cd PsyNeuView                     # main working folder
make dev                          # starts backend :8000 + frontend :5173
# Open http://localhost:5173
```

### Mac App
1. Open PsyNeuView.app (v0.3.1)
2. It auto-pulls from the `stable` branch on launch
3. **Important:** stable is currently behind main. To test latest features:
   - Development menu > Switch Branch > select `main`
   - Or we push main to stable first (recommended)

### Quick test with frontend only (no backend)
```bash
cd PsyNeuView/frontend
npm install && npx vite --port 5179
# Open http://localhost:5179 -- can test palette UI but not model loading
```
