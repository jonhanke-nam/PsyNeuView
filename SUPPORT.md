# Getting help

- **Something isn't working, or you have an idea:** open an issue on this
  repository. Include the version (Settings → About) and what you did. In the
  Mac app, **Help → Report a Problem…** gathers the details for you.
- **How do I…?** Start with the [documentation](docs/introduction.md) and the
  [tutorials](docs/tutorials/README.md); the app's **Tutorials** menu has
  guided walkthroughs.
- **About PsyNeuLink itself** (its models, functions and behaviour): see
  [PsyNeuLink](https://github.com/PrincetonUniversity/PsyNeuLink).
- **Security problems:** see [SECURITY.md](SECURITY.md).
